# Decision Trees, Random Forests, and Isolation Forests from Scratch

This project implements CART-style decision trees, bagging-based random forests, and isolation-forest anomaly detection entirely from scratch using only NumPy — no `scikit-learn` tree, ensemble, or splitting logic. The implementation is built incrementally: starting from a bare `Node`/`Leaf` tree skeleton, then adding depth/node counting, a readable string representation, boundary tracking for fast vectorized prediction, and finally two alternative training strategies (uniformly random splits and Gini-impurity-minimizing splits). The same `Node`/`Leaf` building blocks are then reused to implement isolation trees for unsupervised anomaly detection, and both trees are combined into ensembles (a bagged random forest and an isolation forest).

## Overview

Frameworks like scikit-learn hide the mechanics of recursive partitioning behind a single `.fit()` call. Rebuilding it from scratch forces explicit answers to the questions a tree-based model actually has to solve: how a node picks a feature and threshold to split on, how impurity is measured and minimized without a for-loop over every sample, how a trained tree turns into a fast batch-prediction function instead of one Python recursion per row, how bagging (bootstrap aggregating) reduces the variance of individual high-variance trees by averaging over many of them, and how the isolation-forest principle — anomalies are separated from the rest of the data in fewer random splits than normal points — turns an unsupervised structural property (path length) into an anomaly score. This directory demonstrates that understanding end to end, from a single `Node` object up to a full ensemble used for outlier detection.

## How It Works

### Decision Tree (`8-build_decision_tree.py`)

**Structure.** `Node` holds a `feature` index, a `threshold`, references to `left_child`/`right_child`, its `depth`, and a boolean `sub_population` mask marking which training rows reach it. `Leaf` subclasses `Node`, overriding the traversal methods to terminate recursion and carry a predicted `value` instead of a split.

**Split selection.** Two interchangeable strategies, chosen via `split_criterion` at construction:
- `random_split_criterion` picks a uniformly random feature, then a uniformly random threshold between that feature's min and max over the node's current sub-population.
- `Gini_split_criterion` evaluates **every** feature and **every** candidate threshold (midpoints between consecutive unique sorted values, from `possible_thresholds`) using fully vectorized NumPy broadcasting — no Python loop over samples — and returns the (feature, threshold) pair minimizing the population-weighted Gini impurity `1 - sum(p_c^2)` across the two resulting children.

**Recursive fit.** `fit_node` applies the chosen split criterion to a node, partitions its `sub_population` into `left_population` (feature value `>` threshold) and `right_population` (`<=` threshold), and recurses. A branch becomes a `Leaf` (via `get_leaf_child`, which assigns the majority class with `np.bincount(...).argmax()`) when its population falls below `min_pop`, the next depth would reach `max_depth`, or the remaining targets are already pure (a single class).

**Prediction.** `update_bounds()` propagates per-feature `lower`/`upper` bounds down from the root so each leaf ends up owning an axis-aligned hyper-rectangle of input space; `update_indicator()` turns each leaf's bounds into a vectorized boolean membership test. `update_predict()` then builds `self.predict` as a single NumPy expression that evaluates every leaf's indicator over an entire input batch at once and picks, per row, the value of whichever leaf claims it — avoiding a Python-level tree traversal per sample at inference time. `pred(x)` is the simpler single-sample equivalent that walks the tree node by node.

There is no cost-complexity pruning step in this implementation — tree size is controlled purely through `max_depth` and `min_pop` as pre-pruning stopping conditions.

### Random Forest (`9-random_forest.py`)

`Random_Forest.fit` trains `n_trees` independent `Decision_Tree` instances on the **same full training set**, giving each tree a different `seed` (`self.seed + i`). Because `random_split_criterion`/`Gini_split_criterion` both draw from the tree's own `rng`, and the training procedure itself only samples thresholds (not rows), the variance between trees here comes from the different random split choices at every node rather than classic row/feature bootstrap sampling — the ensemble diversity is seed-driven bagging over split decisions. Each tree exposes its fast vectorized `predict` function; `Random_Forest.predict` stacks all trees' predictions and takes the per-sample majority vote with `np.bincount(...).argmax()`.

### Isolation Forest (`10-isolation_tree.py`, `11-isolation_forest.py`)

`Isolation_Random_Tree` reuses the exact same `Node`/`Leaf` primitives as the decision tree but is trained with `fit(explanatory)` — **no target labels**. Every split is `random_split_criterion` (a random feature, random threshold within the node's current range), and a branch stops — becoming a leaf — as soon as its population size drops to 1 or `max_depth` is reached. Critically, each leaf's stored `value` is its own **depth**, not a class: an isolated point's leaf value directly encodes how many random splits it took to separate that point from the rest.

`Isolation_Random_Forest` trains `n_trees` such trees (again one seed per tree) and, per sample, averages the depth reported by every tree via `predict`. This average path length is the anomaly score exploited by the isolation-forest principle: outliers sit in sparse regions of feature space, so a random split is disproportionately likely to isolate them early, giving them a **short** average depth, while inliers packed together require many splits to separate and get a longer average depth. `suspects(explanatory, n_suspects)` sorts samples by this average depth ascending and returns the `n_suspects` most anomalous points.

- Python 3.12

## Usage

```python
import numpy as np
Random_Forest = __import__('9-random_forest').Random_Forest

def circle_of_clouds(n_clouds, n_objects_by_cloud, radius=1, sigma=None, seed=0):
    """Synthetic dataset: n_clouds gaussian blobs arranged on a circle."""
    rng = np.random.default_rng(seed)
    sigma = sigma or np.sqrt(2 - 2 * np.cos(2 * np.pi / n_clouds)) / 7
    def rotate(x, k):
        theta = 2 * k * np.pi / n_clouds
        m = np.matrix([[np.cos(theta), np.sin(theta)], [-np.sin(theta), np.cos(theta)]])
        return np.matmul(x, m)
    def cloud():
        return (rng.normal(size=2 * n_objects_by_cloud) * sigma).reshape(n_objects_by_cloud, 2) + [radius, 0]
    target = np.array([[i] * n_objects_by_cloud for i in range(n_clouds)], dtype="int32").ravel()
    return np.concatenate([np.array(rotate(cloud(), k)) for k in range(n_clouds)], axis=0), target

explanatory, target = circle_of_clouds(10, 30)
forest = Random_Forest(n_trees=100)
forest.fit(explanatory, target, verbose=1)
```

Output:

```

```

The single-tree string representation (`print(tree)`) renders a readable ASCII diagram, e.g.:

```
root [feature=0, threshold=0.5]
    +---> leaf [value=0]
    +---> node [feature=1, threshold=30000]
           +---> leaf [value=0]
           +---> leaf [value=1]
```

For anomaly detection, `Isolation_Random_Forest.fit(explanatory, verbose=1)` followed by `suspects, depths = forest.suspects(explanatory, n_suspects=3)` returns the points with the smallest average isolation depth alongside their scores.

## Design Notes

- The decision tree supports two interchangeable split strategies — a fast uniformly-random threshold split and a slower but higher-quality Gini-impurity-minimizing split — trading training speed for split quality depending on the use case.
- The Gini split criterion is fully vectorized: it evaluates every feature/threshold combination for a node in one batch of NumPy broadcasting operations instead of looping over samples in Python, which is what makes exhaustive impurity search tractable.
- Prediction is decoupled from tree traversal: once training finishes, `update_predict()` precomputes each leaf's axis-aligned region as a vectorized indicator function, so predicting a whole batch of new points is one array operation rather than one recursive walk per row.
- The random forest and isolation forest both reuse the same `Node`/`Leaf` primitives — only the split criterion, stopping condition, and what a leaf's `value` represents (majority class vs. isolation depth) differ, which keeps the supervised and unsupervised ensembles structurally consistent.
- The isolation forest exploits a purely structural property of random partitioning — anomalies require fewer random splits to isolate than points buried in dense clusters — using average leaf depth across the ensemble as the anomaly score, with no notion of "normal" ever being labeled.
